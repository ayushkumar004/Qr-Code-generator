
# QR Code Generator

A simple and user-friendly QR Code Generator that allows users to generate QR codes by entering any URL or text.

## Features

- Generate QR codes from URLs or text.
- Uses an external API for QR code generation.
- Simple and responsive user interface.
- Quick and easy QR code generation.

## Technologies Used

- HTML
- CSS
- JavaScript
- QR Code API

## How to Use

1. Open the application.
2. Enter your URL or text.
3. Click the **Generate QR Code** button.
4. Your QR code will be displayed.

## API

This project uses an external QR Code API to generate QR codes.
